# VAPT-Capstone

## Comprehensive Vulnerability Assessment and Penetration Testing (VAPT) Capstone Project

This project is the final capstone project completed as part of the Cybersecurity & Ethical Hacking internship/training program at RabTech Academy.

## Project Overview

The objective of this project is to perform a structured Vulnerability Assessment and Penetration Testing (VAPT) of an authorized OWASP Juice Shop training environment.

The assessment focuses on identifying common web application security vulnerabilities, evaluating their severity using CVSS v3.1, mapping them to OWASP Top 10 categories, and providing practical remediation recommendations.

## Objectives

- Identify common web application vulnerabilities.
- Perform authorized security testing in a controlled environment.
- Analyze and document security findings.
- Assign CVSS v3.1 severity scores.
- Map vulnerabilities to OWASP Top 10 categories.
- Provide prioritized remediation recommendations.
- Document retesting and security validation procedures.

## Technologies and Tools

## Key Security Findings

| ID | Finding | Severity |
|---|---|---|
| VAPT-01 | Injection | Critical |
| VAPT-02 | DOM Cross-Site Scripting (XSS) | High |
| VAPT-03 | Broken Access Control | Medium |
| VAPT-04 | Authentication Weakness | Critical |
| VAPT-05 | Sensitive Data Exposure | High |
| VAPT-06 | Security Misconfiguration | High |

## OWASP Mapping

The identified vulnerabilities are mapped to relevant OWASP Top 10 categories including:

- A01 – Broken Access Control
- A02 – Cryptographic Failures
- A03 – Injection
- A05 – Security Misconfiguration
- A07 – Identification and Authentication Failures

- Security testing methodology
